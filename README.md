# 네이버 카페 자동 발행기 — Gemini 워크플로

키워드만 넣으면 **구글 Gemini로 글을 자동 생성**하고, 네이버 카페에 **자동 발행**하는 프로그램의 런처입니다.

## 실행 전 준비 (요약)

- **Google Chrome 설치** + 전용 크롬 프로필로 **gemini.google.com 구글 로그인**
- **안티디텍트 앱 실행** + API 키(sk_…) 발급 → 프로그램의 ‘카페 설정’에 입력
- 각 안티디텍트 프로필에서 **네이버에 1회 수동 로그인** (로그인 유지 → 캡차 회피)
- 첫 실행 시 크롬 드라이버를 자동 다운로드하므로 **인터넷 필요**
